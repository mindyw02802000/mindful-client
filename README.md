# Mindful Client

מערכת לניהול עסק השכרת תלבושות – צד לקוח.

## טכנולוגיות עיקריות
- React
- Redux
- MUI
- CSS, HTML

## תכונות עיקריות
- הזמנת תלבושות דרך האתר
- צפייה בקטלוגים
- ניהול הזמנות למנהלים
- יומן הזמנות

## הוראות התקנה והרצה
1. יש להוריד את הקוד:
git clone https://github.com/mindyw02802000/mindful-client.git

2. להיכנס לתיקיה:
cd mindful-client

3. להתקין חבילות:
npm install
4. להריץ את הפרויקט:
npm start
