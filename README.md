# Mindy-Tzipy Client

מערכת לניהול עסק השכרת תלבושות – צד לקוח.

## טכנולוגיות עיקריות
- React
- Redux
- MUI
- CSS, HTML

## תכונות עיקריות
- הזמנת תלבושות דרך האתר
- צפייה בקטלוגים
- ניהול הזמנות למנהלים
- יומן הזמנות

## הוראות התקנה והרצה
1. יש להוריד את הקוד:
git clone https://github.com/mindi32792/Mindy-Tzipy.git

2. להיכנס לתיקיה:
cd Mindy-Tzipy
3. להתקין חבילות:
npm install
4. להריץ את הפרויקט:
npm start
